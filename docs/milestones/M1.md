# Milestone M1 — The Adjudication Core

Status: complete (week 2–4)

## Scope

Per `AGENTS.md` §30.3: policy registry with versioning, the evidence manifest
with canonical hashing, `adjudicate` with the clause loop and deterministic
aggregation, `safetynet-test` v0.1, `safetynet-sim` v0.1, the first domain lint
rules, and a public StudioNet deployment seeded through synthetic fixtures.

Exit criteria: gate cases 1–5 and 17 pass in sim, and the deployed contract
adjudicates a synthetic incident with a recorded trace.
