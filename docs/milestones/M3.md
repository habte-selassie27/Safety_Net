# Milestone M3 — Trust Hardening

Status: complete for tooling and analysis; network benchmarking outstanding

## Scope

Per `AGENTS.md` §30.5: `snet tighten` stability measurement, `snet fuzz` with
the seven properties, the disagreement corpus, verification levels L0/L1/L4 with
a public artifact, the SSRF suite, the injection resistance suite, and
`snet bench` with a first performance report.

Exit criteria: stability ≥ 90 on reference scenarios at medium noise, zero open
SSRF vectors, published performance report.

## Not shipped

- **Network benchmark samples.** `snet bench` exists; no `bench/<network>-<date>.json`
  has been recorded, so no latency percentiles are published.
- **A published verdict-stability page**: `docs/research/verdict-stability.mdx`
  is referenced but does not exist yet.
- **Release tags.** Only `legacy-v0` exists; the `tag` values in the deployment
  registry are registry labels, not git tags.
- **Sim-mode verdict coverage.** The coverage report flags
  `POLICY_ADEQUATE_BUT_HARM`, `INSUFFICIENT_EVIDENCE`, `OUT_OF_SCOPE` and
  `DISMISSED` as not covered by sim-mode adjudication, though direct mode and
  `aggregate.test.ts` exercise them.

## Notes

The high-noise 64/100 result is the honest cost of `strict_eq` over a clause set:
two or three divergent validators force an appeal round. It is documented rather
than hidden, and it is the strongest argument for treating severity bands as the
next tightening target.
